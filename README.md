# Portafolio — Gadiel Abraham Peña Hernández

Sitio personal de proyectos de Business Intelligence y automatización.

## Estructura

```
index.html      Sitio completo (HTML + CSS + JS en un solo archivo)
assets/         Capturas de los proyectos
```

## Cómo editar

No necesita compilarse. Se edita `index.html` y los cambios se publican
al hacer commit.

**Datos de contacto:** al final del archivo, sección `id="contacto"`.
Buscar `TU_CORREO`, `TU_LINKEDIN` y `TU_WHATSAPP`.

**Agregar un proyecto:** copiar un bloque `<article class="project"> … </article>`
completo y pegarlo donde corresponda. El atributo `data-tags` controla en qué
filtros aparece; los valores válidos son: `powerbi`, `powerapps`, `automate`,
`sharepoint`, `datos`.

## Confidencialidad

Las capturas de proyectos privados tienen difuminadas las cifras y los nombres
de proyecto. Los archivos fuente (.pbix, .msapp, definiciones de flujo) **no se
publican en este repositorio**: contienen identificadores de entorno y datos
internos del cliente.

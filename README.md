# Portafolio — Gadiel Abraham Peña Hernández

Sitio personal de proyectos de Business Intelligence y automatización
con Power BI, Power Apps, Power Automate y SharePoint.

## Estructura

```
index.html      Sitio completo (HTML + CSS en un solo archivo)
assets/         Capturas de los proyectos
```

## Cómo editar

El sitio no necesita compilarse. Se edita `index.html` directamente
y los cambios se publican solos al hacer commit.

**Datos de contacto:** están al final del archivo, en la sección
`id="contacto"`. Buscar `TU_CORREO`, `TU_LINKEDIN` y `TU_WHATSAPP`.

**Agregar un proyecto:** copiar el bloque completo
`<article class="project"> … </article>` y pegarlo antes del
`<div class="upcoming">`. Cada proyecto necesita las tres respuestas
del bloque `.psr`: problema, solución y resultado.

## Nota sobre confidencialidad

Las capturas del proyecto de CEMEX tienen difuminadas las cifras
y los nombres de los proyectos. Los archivos fuente (`.pbix`,
`.msapp`, definiciones de flujo) **no se publican en este repositorio**:
contienen identificadores de entorno y datos internos del cliente.
